# ХимКабинет — платформа репетитора по химии

Веб-платформа с личными кабинетами **преподавателя** и **ученика** (плюс страница для родителей).
Работает в браузере на компьютере и телефоне, ставится на телефон как приложение.

Для запуска нужен только **Node.js 22.5+**. Сторонние библиотеки не используются, `npm install` не нужен.
Все данные лежат в одном файле SQLite: `data/chemtutor.db`.

## Запуск на своём компьютере

1. Установите **Node.js** версии LTS (22.13 или новее) с https://nodejs.org. Это один установщик, настройки по умолчанию подходят.
2. Распакуйте архив `chemtutor.zip` в удобную папку, например `Документы\ХимКабинет`.
3. Запустите двойным щелчком:
   - **Windows:** `start.bat`;
   - **Mac:** `start.command`. При первом запуске macOS может его заблокировать: нажмите на файл правой кнопкой и выберите «Открыть».

Откроется окно с сервером, а браузер сам перейдёт на http://localhost:3000. Пока окно открыто, платформа работает. Закрыли окно — платформа остановилась, данные сохранены в папке `data`.

Так платформа доступна только на этом компьютере. Чтобы ученики заходили со своих устройств, её нужно выложить на сервер (раздел «Как выложить в интернет» ниже).

**Продолжить доработку с Claude Code локально:** откройте терминал в папке проекта и выполните `claude`. В архиве есть вся история изменений в git.

## Быстрый старт из терминала

```bash
npm start            # http://localhost:3000
```

При первом открытии платформа попросит создать аккаунт преподавателя. Сразу после этого в кабинет добавляются:

- банк из **192 задач** по 35 темам ЕГЭ/ОГЭ с ответами и разбором;
- **8 колод карточек**: элементы, кислоты и соли, тривиальные названия, качественные реакции, цвета осадков, органика, именные реакции, формулы для задач;
- **5 конспектов**: классы неорганических веществ, ОВР, задачи на растворы, гидролиз, изомерия.

Всё это можно редактировать и удалять.

Чтобы посмотреть платформу на тестовых данных, нажмите **«Создать демо-данные»** на главной или в настройках. Появятся 3 ученика с расписанием, оплатами и сданными работами; их логины `demo1`–`demo3`, пароль `demo123`.

Если нужна отдельная демо-база:

```bash
DATA_DIR=./demo-data npm run demo   # teacher / teacher123, ученики demo1..3 / demo123
DATA_DIR=./demo-data npm start
```

В Windows (PowerShell):

```powershell
$env:DATA_DIR="./demo-data"; npm run demo; npm start
```

## Что умеет

### Кабинет преподавателя
- **Главная.** Занятия на сегодня и ближайшие дни, работы на проверку, прошедшие занятия без отметки, просроченные ДЗ, должники, доход и число занятий по месяцам, личный список дел.
- **Ученики.**
  - Карточка ученика: класс, цель (ЕГЭ/ОГЭ/олимпиада), целевой балл, цена занятия, контакты ученика и родителя, приватные заметки, архив.
  - Ученик входит по ссылке-приглашению. Её можно отправить в Telegram или WhatsApp одной кнопкой. Если удобнее, логин и пароль задаются вручную.
  - Профиль ученика: баланс, средний балл, посещаемость, график результатов, пробники, слабые темы по статистике ответов, тепловая карта активности, достижения.
  - **Карта знаний** по 35 темам с оценкой 0–5 и радар-диаграммой по разделам.
  - **Страница для родителей** по секретной ссылке, без входа: посещаемость, итоги занятий, результаты, карта знаний, баланс.
- **Расписание.**
  - Вид неделей, месяцем или списком. Повторяющиеся занятия: раз в неделю, на полугодие или на год.
  - Проверка пересечений по времени.
  - Статусы: проведено, отменено, пропуск. План занятия и итоги видят ученик и родитель.
  - Ссылка на Zoom или Телемост.
  - Экспорт в CSV и подписка в Google/Яндекс/Apple Календарь (.ics с напоминанием за 30 минут).
- **Задания и тесты.**
  - Типы вопросов: один ответ, несколько ответов (баллы считаются как в ЕГЭ: одна ошибка — минус балл), число с допуском, короткий ответ (несколько вариантов написания, регистр и ё/е не важны), развёрнутый ответ с фото решения.
  - Картинки в вопросах.
  - Формулы пишутся обычным текстом (`H2SO4`, `Fe^3+`, `SO4^2-`, `->`), индексы расставляются автоматически.
  - Вопросы берутся из банка или подбираются **генератором вариантов** (N случайных задач из каждой выбранной темы).
  - Тесты на время с автосдачей по таймеру.
  - Задание выдаётся нескольким ученикам сразу со сроком сдачи. Есть статистика по каждому вопросу (сколько процентов ответили верно) и печать.
- **Проверка.** Автопроверка закрытых вопросов. Развёрнутые ответы оцениваются вручную, баллы автопроверки можно поправить. Комментарий к каждому ответу и общий. Можно вернуть работу на доработку или дать пересдачу.
- **Банк задач.** Фильтры по теме, типу и сложности, поиск. Из выбранных вопросов задание создаётся в один клик.
- **Материалы.** Конспекты в Markdown с предпросмотром, файлы до 15 МБ (PDF открывается прямо на странице), ссылки. Доступ всем или выбранным ученикам, закрепление, уведомление ученикам, счётчик просмотров.
- **Карточки.** Редактор колод и вставка списком прямо из Excel.
- **Финансы.**
  - Оплаты с быстрыми суммами («4 занятия»).
  - Баланс ученика: оплаты минус проведённые и пропущенные занятия.
  - Доход по месяцам, начисления, средний доход в час, прогноз на месяц.
  - Должники и готовый текст напоминания об оплате.
  - Выгрузка CSV для Excel.
- **Сообщения.** Чат с каждым учеником: файлы, фото, отметки о прочтении. Рассылка всем ученикам.
- **Общее.** Уведомления, быстрый поиск **Ctrl+K**, тёмная тема.

### Кабинет ученика
- **Главная.** Уровень и XP, серия дней 🔥, цель и последний пробник, задания со сроками, кнопка «Подключиться» за 30 минут до урока, совет дня по химии.
- **Расписание.** Планы и итоги занятий, оценка урока, добавление в календарь телефона.
- **Задания.** Автосохранение ответов, навигация по вопросам, таймер в тестах, фото решения с телефона (большие снимки сжимаются). После сдачи показываются результат и разбор, при хорошем результате — салют 🎉.
- **Работа над ошибками.** Сюда автоматически попадают вопросы, где была ошибка, и их можно перерешать.
- **Тренажёр.** Случайные задачи из банка по выбранной теме с мгновенной проверкой и разбором.
- **Карточки.** Интервальное повторение по системе Лейтнера, управление с клавиатуры.
- **Мой прогресс.** Графики, карта знаний, слабые темы, тепловая карта, 14 достижений, рейтинг учеников по XP.
- **Фокус-таймер.** Помодоро 25/5 с XP за каждую сессию.
- **Чат с преподавателем** и **профиль** с балансом и историей оплат.

### Химические инструменты (доступны всем, даже без входа)
- Интерактивная **таблица Менделеева**: 118 элементов, поиск, подсветка по типу, электроотрицательности и агрегатному состоянию, полная карточка элемента.
- **Молярная масса** с массовыми долями и пересчётом г ↔ моль ↔ частицы ↔ литры.
- **Уравнивание реакций**, в том числе ОВР и ионных уравнений с зарядами, с таблицей проверки атомов.
- **Растворы**: ω, C, разбавление, смешивание, правило креста (конверт Пирсона) и перевод ω ↔ C. Каждый калькулятор показывает решение по шагам.
- **Газы**: pV = nRT, расчёты при н.у., относительная плотность.
- **pH** сильных и слабых кислот и оснований.
- **Таблица растворимости**, **ряд активности металлов**, ряд электроотрицательности.
- **Тренажёр**: элементы, степени окисления, растворимость.

> Проверьте строки таблицы растворимости для фторидов, гидро- и дигидросолей, нитритов и HSO₄⁻/HSO₃⁻: в разных школьных изданиях они отличаются. Данные лежат в `public/js/chem/tools.js`, массив `ANIONS`.

## Как выложить в интернет

Платформа — один Node.js-процесс без зависимостей. Хватает самого дешёвого VPS (Timeweb, Selectel, Reg.ru, любой другой).

```bash
# на сервере (Ubuntu)
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash - && sudo apt install -y nodejs
git clone <ваш репозиторий> chemtutor && cd chemtutor   # или загрузите архив
PORT=3000 TZ=Europe/Moscow COOKIE_SECURE=1 npm start
```

Чтобы процесс работал постоянно, создайте `/etc/systemd/system/chemtutor.service`:

```ini
[Unit]
Description=ChemTutor
After=network.target

[Service]
WorkingDirectory=/home/ubuntu/chemtutor
ExecStart=/usr/bin/npm start
Environment=PORT=3000 TZ=Europe/Moscow COOKIE_SECURE=1
Restart=always
User=ubuntu

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now chemtutor
```

HTTPS обязателен, потому что ученики вводят пароли. Проще всего поставить **Caddy**, он сам получит сертификат:

```
# /etc/caddy/Caddyfile
chem.ваш-домен.ru {
  reverse_proxy localhost:3000
}
```

Подойдёт и любой хостинг с Node.js и постоянным диском (Railway, Render, Fly.io с volume). Папку `data/` нужно сделать постоянным томом: в ней лежат база и файлы.

### Переменные окружения
| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт |
| `TZ` | `Europe/Moscow` | часовой пояс расписания |
| `DATA_DIR` | `./data` | где хранить базу и загруженные файлы |
| `COOKIE_SECURE` | — | `1` за HTTPS: cookie отправляются только по защищённому соединению |

### Резервные копии
```bash
npm run backup        # копия базы в data/backups (хранятся последние 30)
```
Добавьте ежедневный запуск в cron: `0 4 * * * cd /home/ubuntu/chemtutor && npm run backup`. Для полной копии сохраняйте всю папку `data/`: в ней ещё и загруженные файлы.

## Устройство

```
server/
  server.js        HTTP-сервер (node:http), маршрутизация, защита от CSRF, ограничение частоты входа
  db.js            схема SQLite (node:sqlite)
  auth.js          пароли (scrypt), сессии в HttpOnly-cookie, приглашения
  grade.js         автопроверка, XP, уровни, серии, достижения, баланс
  seed.js          стартовый контент и демо-данные
  routes/          common (вход, файлы, чат, уведомления, родители, .ics), teacher, student
  seed/            банк задач, темы, карточки, конспекты (JSON/Markdown)
public/
  index.html, css/, sw.js, manifest   SPA без сборки, PWA
  js/app.js        роутер и оболочка кабинетов
  js/ui.js         компоненты, графики (SVG), markdown
  js/views/        экраны (t-* для преподавателя, s-* для ученика)
  js/chem/         таблица Менделеева, парсер формул, уравнивание, калькуляторы
tests/             npm test
```

Безопасность:
- Пароли хранятся как scrypt-хеш с солью. Сессии живут в HttpOnly-cookie с SameSite=Lax.
- Изменяющие запросы с чужого Origin отклоняются, тело запроса принимается только как JSON.
- Попытки входа ограничены: 20 за 10 минут с одного IP.
- Каждый запрос проверяет, что преподаватель видит только своих учеников, а ученик — только свои данные. Правильные ответы не уходят ученику до сдачи работы.
