# Классы неорганических соединений

Почти любое задание ОГЭ и ЕГЭ по неорганике начинается с одного вопроса: *к какому классу относится вещество?* Если класс определён верно, свойства «достраиваются» сами. Поэтому эту тему стоит знать уверенно, до автоматизма.

## Общая схема

Все неорганические вещества делятся на **простые** (из атомов одного элемента) и **сложные**.

- Простые вещества: металлы (Na, Fe, Cu) и неметаллы (O2, N2, S, P, Cl2).
- Сложные вещества: оксиды, гидроксиды (основания, кислоты, амфотерные гидроксиды) и соли.
- Отдельно стоят бинарные соединения, которые не являются оксидами: гидриды (NaH), сульфиды (FeS), нитриды (Li3N), карбиды (CaC2) и т. д.

## Оксиды

Оксид — сложное вещество из двух элементов, один из которых кислород в степени окисления −2. Поэтому H2O2 и BaO2 — **пероксиды**, а не оксиды, а OF2 — фторид кислорода.

| Тип оксида | Кто образует | Примеры | Чему соответствует |
|---|---|---|---|
| Основный | металлы в степени окисления +1, +2 (кроме Be, Zn, Sn, Pb) | Na2O, CaO, FeO, CuO | основание |
| Амфотерный | металлы в степени окисления +3, +4, а также Be, Zn, Sn, Pb в +2 | Al2O3, ZnO, Cr2O3, Fe2O3, BeO | амфотерный гидроксид |
| Кислотный | неметаллы; металлы в степени окисления +5 и выше | SO3, P2O5, CO2, CrO3, Mn2O7 | кислота |
| Несолеобразующий | некоторые неметаллы | CO, NO, N2O, SiO | ничему |

> Запомните: у одного и того же элемента с ростом степени окисления свойства оксидов меняются от основных к кислотным. CrO — основный, Cr2O3 — амфотерный, CrO3 — кислотный.

### Химические свойства оксидов

- Основный оксид + кислота -> соль + вода: CuO + H2SO4 -> CuSO4 + H2O.
- Основный оксид + кислотный оксид -> соль: CaO + CO2 -> CaCO3.
- С водой реагируют только оксиды щелочных и щёлочноземельных металлов (начиная с Ca): CaO + H2O -> Ca(OH)2.
- Кислотный оксид + щёлочь -> соль + вода: SO2 + 2NaOH -> Na2SO3 + H2O.
- Кислотный оксид + вода -> кислота (кроме SiO2): SO3 + H2O -> H2SO4.
- Амфотерный оксид реагирует и с кислотами, и со щелочами: ZnO + 2HCl -> ZnCl2 + H2O; ZnO + 2NaOH + H2O -> Na2[Zn(OH)4].

## Основания

Основания — вещества, которые при диссоциации образуют из анионов только гидроксид-ионы OH^-. Делятся на **щёлочи** (растворимые: LiOH, NaOH, KOH, RbOH, CsOH, Ca(OH)2, Sr(OH)2, Ba(OH)2) и **нерастворимые** (Cu(OH)2, Fe(OH)2, Mg(OH)2).

Главные свойства:

1. Щёлочи меняют окраску индикаторов: фенолфталеин — малиновый, лакмус — синий.
2. Реагируют с кислотами (нейтрализация): NaOH + HCl -> NaCl + H2O.
3. Щёлочи реагируют с кислотными оксидами и с растворами солей, если образуется осадок: 2NaOH + CuSO4 -> Cu(OH)2 + Na2SO4.
4. Нерастворимые основания разлагаются при нагревании: Cu(OH)2 -> CuO + H2O. Щёлочи (кроме LiOH) при нагревании не разлагаются.

## Кислоты

Кислоты — вещества, которые при диссоциации образуют из катионов только ионы H^+. Классифицируют по основности (HCl — одноосновная, H2SO4 — двухосновная, H3PO4 — трёхосновная), по наличию кислорода и по силе.

| Сильные | Средней силы | Слабые |
|---|---|---|
| HCl, HBr, HI, HNO3, H2SO4, HClO4 | H3PO4, H2SO3, HF* | H2CO3, H2S, H2SiO3, HNO2, CH3COOH |

*HF часто относят к слабым кислотам — ориентируйтесь на формулировку задания.

Типичные реакции кислот:

- с металлами, стоящими в ряду напряжений до водорода: Zn + 2HCl -> ZnCl2 + H2 (азотная и концентрированная серная кислоты ведут себя иначе — водород не выделяется);
- с основными и амфотерными оксидами, с основаниями;
- с солями, если образуется осадок, газ или более слабая кислота: Na2CO3 + 2HCl -> 2NaCl + CO2 + H2O.

## Амфотерные гидроксиды

Al(OH)3, Zn(OH)2, Be(OH)2, Cr(OH)3, Fe(OH)3 (слабо амфотерен) реагируют и с кислотами, и со щелочами:

```
Al(OH)3 + 3HCl -> AlCl3 + 3H2O
Al(OH)3 + NaOH -> Na[Al(OH)4]          (в растворе)
Al(OH)3 + NaOH -> NaAlO2 + 2H2O        (при сплавлении)
```

## Соли

| Тип соли | Определение | Пример | Название |
|---|---|---|---|
| Средняя | все атомы H кислоты замещены на металл | Na2SO4 | сульфат натрия |
| Кислая | замещены не все атомы H | NaHSO4 | гидросульфат натрия |
| Основная | не все группы OH основания замещены | (CuOH)2CO3 | дигидроксокарбонат меди(II) |
| Двойная | два разных катиона | KAl(SO4)2 | сульфат алюминия-калия |
| Комплексная | содержит комплексный ион | K3[Fe(CN)6] | гексацианоферрат(III) калия |

Название средней соли: *кислотный остаток + металл (валентность, если она переменная)*. Например, Fe2(SO4)3 — сульфат железа(III), KNO2 — нитрит калия.

## Пример рассуждения

**Задание.** Выберите вещества, с которыми реагирует оксид цинка: NaOH, H2O, HCl, CaO, Na2SO4.

**Решение.** ZnO — амфотерный оксид. Значит, он реагирует с кислотами (HCl) и со щелочами (NaOH). При сплавлении он реагирует и с основным оксидом CaO, образуя цинкат CaZnO2. С водой ZnO не реагирует, с сульфатом натрия — тоже. Ответ: NaOH, HCl, CaO.

## Типичные ошибки

- Считать Mn2O7 или CrO3 основными оксидами «потому что металл». Смотрите на степень окисления: +6 и +7 — кислотные оксиды.
- Забывать, что CO, NO и N2O — несолеобразующие и со щелочами не реагируют.
- Писать реакцию SiO2 с водой. Кремниевую кислоту получают только косвенно: Na2SiO3 + 2HCl -> H2SiO3 + 2NaCl.
- Путать KClO3 (хлорат) и KClO4 (перхлорат), Na2SO3 (сульфит) и Na2SO4 (сульфат).
- Называть H2O2 оксидом: в нём есть связь O–O, это пероксид.
